# Main User Flow — Agency Management SaaS

## Primary User
Agency Owner / Project Manager

## Main Flow

Login
→ Dashboard
→ View Active Projects
→ Open Project
→ Review Tasks
→ Assign Team Member
→ Update Task Status
→ Check Project Progress
→ Create or Review Invoice
→ Track Payment Status
→ View Income & Expenses
→ Return to Dashboard

## Key Actions

- Create a new project
- Add and assign tasks
- Add clients
- Monitor project progress
- Generate invoices
- Track paid and unpaid invoices
- Record expenses
- Review business performance

## Navigation Structure

Dashboard  
→ Projects  
→ Tasks  
→ Clients  
→ Invoices  
→ Expenses  
→ Reports  
→ Notifications  
→ Settings

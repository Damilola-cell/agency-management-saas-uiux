# Wireframes — Agency Management SaaS

## Purpose

The wireframes establish the information architecture, content hierarchy and core interactions before moving into high-fidelity UI design.

## Core Screens

1. Dashboard
2. Projects
3. Project Details
4. Tasks
5. Clients
6. Client Details
7. Invoices
8. Create Invoice
9. Expenses
10. Reports
11. Notifications
12. Settings

## Priority Screens

The first design phase will focus on:

- Dashboard
- Projects
- Project Details
- Tasks
- Invoices
- Reports

## Dashboard Structure

The dashboard should provide an at-a-glance view of:

- Active projects
- Tasks requiring attention
- Project progress
- Revenue and expenses
- Outstanding invoices
- Recent activity
- Quick actions
